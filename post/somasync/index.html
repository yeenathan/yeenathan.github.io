SomaSync

React.jsTypeScriptAWSBackendDeploymentHeadless Wordpress

Not currently online

A psychological health and safety learning web application I worked on over a little under 2 months for my practicum. Learned a lot about deployment and back-end systems as it was my first exposure to many tools.

SomaSync was built from scratch using Wordpress as a backend with a custom React web app frontend, deployed using AWS services (Lightsail, Amplify, S3, CloudFront, etc.). The decision was made to use Wordpress because it comes with user group functionality and an admin dashboard built-in, which was useful considering the short time-frame.

While it was a short term project I learned a lot about AWS and deployment, php, DNS and domain management, and integrating frontend/backend together from this experience.
